# 套利监测看板

跨品种比价与价差看板，独立项目目录为 `D:\arbitrage-dashboard`。本地每日更新，并通过 GitHub `main` 自动触发 Cloudflare Pages 发布静态快照。

国内行情以 `xtdata` 为唯一主源；外部补充包括 LME/FCPO、CBOT 美豆油与美豆粕、新浪美股指数、中证指数估值、中美10年期国债收益率、Multpl 标普500市盈率、外管局汇率、纽约联储 OBFR 和美联储理事会 IOER/IORB，均写入共享目录并接受完整性校验。

## 数据流程

1. `scripts/update_xtdata.py` 连接 `xtdata`，下载商品期货持仓量加权连续、商品与股指期货主力连续、具体月份和现货指数的全部可得日线历史。
2. xtdata 数据写入 `E:\data\market\futures_daily` 和 `E:\data\market\index_daily`。
3. 脚本更新 `catalog.sqlite`、`manifest.jsonl` 和完整性报告。
4. 35 组主表指标、3 个展开利润观察口径及常规期货组合成交量最大的 4 个共同合约月写入 `app/data/arbitrage.json`，网站从该文件渲染。
5. 看板主日期取国内 xtdata 最新完整交易日；外盘和外部指标保留各自实际来源日，允许在最大滞后范围内向后匹配，不再因 LME 尚未收盘而回退全部国内行。
6. Windows 计划任务在周一至周五 20:10 从 `D:\arbitrage-dashboard-publisher` 独立 worktree 检查更新；校验和静态页面测试通过后，只提交 `app/data/arbitrage.json` 并推送 `main`。节假日且规范化内容不变时自动跳过。

## 图表

- 分位总览：全部 35 个主表品种对的近 5 年分位横向排名，统一使用 0%–100% 量尺。
- 历史走势：IC/IF、IM/IF、科创50/上证50、创业板/沪深300、IM-IC价差、蛋白质价差。
- 历史窗口：所有折线图最近 20 个交易日展示日线收盘，更早历史按每周最后一个实际交易日取点；展开图保留既定十年窗口，底部分析图保留近五年窗口。3%/97%阈值、全历史/近5年分位、区间、均线和当前值始终基于完整日频数据计算，绘图压缩不参与统计。
- 图表数据：国内行情来自 xtdata；海外期货、海外指数、估值、国债收益率和汇率来自项目规则列明的已批准外部源。跨日合并只向后匹配已公布数据；外部来源日早于国内主日期时，品种对名称旁显示“外部截至 MM-DD”。
- 现货指数叠加：IC/IF 比价的现货指数图右轴叠加中证500，IM/IF 比价与 IM-IC 价差的现货指数图右轴叠加中证1000，数据均来自 xtdata。三张图右上角展示完整日频的10年水平 Pearson 相关系数和日变动 Pearson 相关系数；日变动统计中，比价使用日收益率，价差使用一阶差分，叠加的现货指数使用日收益率。主连图、月份图和其他套利对沿用原展示。

## Cloudflare Pages

Cloudflare Pages 使用静态快照构建，不运行本机 xtdata 更新接口。项目设置如下：

- Production branch：`main`
- Build command：`npm run build:pages`
- Build output directory：`dist/client`
- Root directory：仓库根目录（留空）
- Node.js：遵守 `package.json` 中的 `>=22.13.0`

构建命令会先完成 Vinext 构建，再把服务器渲染的首页导出为 `dist/client/index.html`；`npm run test:pages` 可同时验证首页、客户端资源和原有看板测试。云端页面只展示提交时的 `app/data/arbitrage.json`，本机的“立即更新数据”功能在云端会自动显示为“云端数据快照”。

Cloudflare 连接的 Git 仓库必须包含当前代码；部署页面显示的提交号应与准备发布的提交一致。

`scripts/update-and-publish.ps1` 是唯一获准自动执行 `git push` 的入口。计划任务使用 `automation/publisher` 独立分支，自动快进 `origin/main`；完整性报告必须确认国内数据日符合交易日历、外部行披露实际来源日。规范化数据内容有实质变化时才运行 `npm run test:pages`、仅提交 `app/data/arbitrage.json` 并推送 `main`；只有 `updatedAt` 变化时会恢复生成文件并跳过。若上次数据提交因网络中断未推送，下一次会验证提交只修改数据文件后重试 `HEAD:main`。Cloudflare 验收同时核对国内数据日和快照时间，避免同日期内容误判为已部署。任何一步失败都会停止发布、写入独立 worktree 的 `.runtime/cloud-publish-status.json` 并尝试显示 Windows 通知；计划任务配置每 10 分钟重试，最多 3 次。

安装或刷新计划任务：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\install-update-and-publish-task.ps1
```

无更新、无提交、无推送的安全演练：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\update-and-publish.ps1 -DryRun
```

## 口径

- 行情源：展示值、历史分位、手数和保证金均仅使用 `xtdata`。
- 默认合约：商品套利使用 `JQ00` 持仓量加权连续序列；股指期货套利继续使用 `00` 主力连续序列。商品 `00` 主连保留在月份展开区，可手动设为主要观察。
- 股指期限套：IM 使用 `(IM当月 − IM下季/隔季) × 12 / 月差 / 中证1000`，IC 使用 `(IC当月 − IC下季/隔季) × 12 / 月差 / 中证500`；月差按两张具体合约之间的自然月数计算，主表、展开表和历史图统一按年化百分数呈现。下季、隔季分别取排在下月之后的第一、第二个季月合约；当月合约正常跟踪至到期，到期后才自然切换为次月。历史序列仅使用同日 xtdata 收盘价和预先可知的交易日历，不按未来成交量倒推合约。
- 月份展开：默认折叠；点击品种对前的 `+` 展开。展示共同合约月、当前值、两腿成交量、近 5 年分位和判断。
- 月份排序：按两腿当日成交量的较小值（可配对成交量）降序，取前 4 个共同月份。
- 当前值与前日值：最近两个共同交易日的收盘价计算结果。
- 全历史分位：`xtdata` 返回的全部可得日线历史。
- 近 5 年分位：最新数据日前滚动五年的日线历史。
- 判断：5% 以下为“极度偏低”，5%–15% 为“偏低”，85%–95% 为“偏高”，95% 以上为“极度偏高”，其余为“中性”。
- 平衡手数：价差组合固定为 1:1；比价组合遍历两腿各 1–20 手的整数组合，选择名义市值偏差最小的一组，偏差相同时优先总手数更少的组合。
- 保证金：使用脚本内配置的保证金比例估算；中金所股指期货组合按跨品种冲抵口径取两腿中较大的单边保证金，其他组合按两腿相加，不代表账户实际占用。
- 商品组合：蛋白质价差（豆粕减菜粕）及油脂比价均使用 xtdata `JQ00` 加权序列作为默认展示口径。棕榈油/菜油比价=`P/OI`、棕榈油/豆油比价=`P/Y`、菜油/豆油比价=`OI/Y`，三项月份展开均限制为1、5、9月共同合约。科创50/上证50、创业板/沪深300使用 xtdata 现货指数，只作风格参考，因此不展示平衡手数、名义值和保证金。
- IM-IC价差：中证1000股指期货减中证500股指期货；卷-螺价差：热卷减螺纹钢；螺/矿比价：螺纹钢除以铁矿石；焦炭/焦煤比价：焦炭除以焦煤；豆一/豆二比价：豆一除以豆二；豆粕/豆二比价：豆粕除以豆二（`M/B`），默认使用 `mJQ00.DF / bJQ00.DF`，展开显示1、5、9月共同合约；油/粕比价：豆油除以豆粕；金/银比价：黄金价格乘 1000 后除以白银价格。
- 新增比价：玻璃/纯碱、铜/铝、聚丙烯/甲醇、燃料油/沥青、20号胶/BR橡胶、烧碱/玻璃、镍/不锈钢、猪肉/玉米及三项油脂比价均按左腿除以右腿计算。玻璃与聚乙烯、聚丙烯缺少直接产业锚，已从看板删除。
- 价差与利润代理：MTO盘面利润=`PP−3×MA` 放在“聚丙烯/甲醇比价”的展开观察口径中，玻璃生产利润=`FG−0.2×SA` 放在“玻璃/纯碱比价”的展开观察口径中，焦化利润=`J−1.3×JM` 放在“焦炭/焦煤比价”的展开观察口径中，三项均排在各自加权行上方。全部使用 xtdata `JQ00` 持仓量加权序列；展开利润观察配比分别按 `2:3`、`5:1` 与 `6:13` 展示，并各自提供分位判断与历史图。
- 风险溢价：ERP：沪深300=`100/沪深300滚动市盈率−中国10年期国债收益率`，图中使用固定 3% 与 6% 阈值线，类型为“回归”；ERP：标普500=`100/标普500市盈率−美国10年期国债收益率`，继续使用历史 3%/97% 分位阈值，类型为“外盘监控”。两项按百分数显示，并固定排在看板第一、第二位。
- 美元银行融资压力代理：`（OBFR−准备金管理利率）×100`，单位为基点。OBFR 是纽约联储公布的广义无担保隔夜银行融资利率；准备金管理利率自 2021-07-29 起使用 IORB，此前使用其官方前身 IOER。利差上冲表示银行批发无担保融资相对准备金管理利率变贵。展开图左轴展示融资压力，右轴叠加新浪标普500指数作市场对照。它固定排在第三位，可从 OBFR 起始日 2016-08-25 形成近10年历史，但仍只是银行融资压力代理，不能替代交叉货币基差、信用利差和市场深度组成的完整离岸美元监测。
- 海外相对指标：纳斯达克/标普500使用两只现货指数收盘价；马盘棕榈油/美盘豆油直接使用 `FCPO（林吉特/吨）÷ CBOT美豆油（美分/磅）` 的原始报价比，不做单位或汇率换算；美盘油粕比=`CBOT美豆油（美分/磅）×20÷CBOT美豆粕（美元/短吨）`，先把两腿统一为美元/短吨再计算。

## 安全与失败处理

`xtdata` 凭证只从 `XTQUANT_TOKEN` 环境变量或本机 `E:\data\config.py` 读取，不写入项目。若 xtdata 行情不可用、35 组主表数据或3个展开利润观察不齐、批准的外部数据缺失或过期、交易日不一致或检测到未来数据，脚本保留上次有效网页数据并记录 `xtdata_unavailable`、`external_source_unavailable` 或校验错误，不发布异常结果。
